# ⚡ UI Macro Builder

Excel VBA を **ブロックを組み立てるだけ** で作れる、授業用のビジュアルプログラミング学習ツール。
ループ・条件分岐・配列のアルゴリズムを、目で見ながら学べます。

🔗 **使う**: https://mkt918.github.io/ui-macro-builder/

---

## 生徒のみなさんへ — 使い方

1. **🎮 クエスト選択** ボタンから、挑戦するクエストを選ぶ
2. プリントに **流れ図（フローチャート）** を書く
3. 左のブロックを中央のエリアに **ドラッグ＆ドロップ** して組み立てる
4. 右の **仮想 Excel** で、ブロックがどう動くか確認する
   - **▶ 実行**: 全部を自動で動かす（速度はスライダーで調整）
   - **⏭ ステップ**: 1つずつ進めて、何が起きるか確かめる
   - **↺ リセット**: 最初に戻す
5. うまくいったら **🎉 クエストクリア！** が出る
6. 詰まったら **💡 ヒント**（3段階）を順番に見る
7. どうしても分からなければ **📖 答えを見る**（確認のあと表示）
8. できた VBA コードは **📋 コピー** して、本物の Excel に貼り付けて実行！

### 🤖 VBAコードタブは直接編集もできます

「🤖 VBAコード」タブでは、コードを自分で書き換えることもできます。

- `For` `Dim` `While` `Until` `If` `Ifelse` などのキーワードを打つと、例文の候補が自動でポップアップ表示されます。↑↓キーで選んで **Enter**（またはクリック）すると骨組みが入力されます。**Esc** キーでポップアップだけ閉じられます
- 改行やキーワード（`Next` `Loop` `End If` など）でインデントが自動調整されます
- 書いたコードは、**🧩 ブロック タブに戻ると自動でブロックに変換**されます
  - うまく変換できない書き方（対応していない構文）のときはエラーが出て、
    直すまでブロックには反映されません。焦らず直しましょう

### 📖 VBA逆引きリファレンスを見ながら書ける

右上の **📖 リファレンス** ボタン（または仮想Excel欄の「📖 リファレンス」タブ）を押すと、
右側が構文集に切り替わります。コード（左〜中央）を見たまま参照できるので、
「For文の書き方を忘れた」「Dimってどう書くんだっけ」というときに便利です。
**📊 仮想Excel** タブでいつでも元の画面に戻れます。

### ブロックの種類
| カテゴリ | できること |
|---------|-----------|
| 🟦 セル操作 | セルに値を入れる・取り出す・コピー・消す |
| 🟧 繰り返し | 同じことを何回もくり返す（ループ） |
| 🟪 条件分岐 | もし〜なら、で処理を分ける |
| 🟩 書式設定 | 背景色を変える・太字にする |
| 🟢 配列 | データを「はこの列」にためる |
| 🟥 シート操作 | シートを追加・切り替え |
| 🔵 値 | 数字・テキスト・計算 |

🌙/☀️ ボタンで **ダークモード / ライトモード** を切り替えられます。
