## 修正（2026-09-24 QA診断からの対応）

アプリ全体のQA診断（要件照合＋利用シナリオ＋Web観点チェック）で見つかった10件の指摘を、
すべて修正した。各項目は該当する再現手順で実ブラウザ確認済み。

1. **変数名を「i」/「arr」にすると生成VBAが二重Dimでコンパイル不能** →
   `src/vba-generator.js` の `generateVBA()` で Dim 済み名を `declared` Set で
   重複排除。確認: 変数名"i"で `Dim i` が1回のみ出力されることを実ブラウザで確認
2. **ひらがな変数名バリデーションが「＋変数を作る」ボタンをバイパスできた** →
   `src/blockly-setup.js` に共通検証関数 `validateVarNameMessage`（ひらがな＋
   予約語 i/arr を拒否）を追加し `window.UMB_validateVarName` として公開。
   `src/app.js` の `CREATE_VARIABLE_JP` ボタンコールバックを自前実装
   （`promptNewVariableName`）に差し替え、同じ検証を通すよう修正。
   確認: 「ごうけい」「i」「arr」はすべて拒否、正常な名前だけ作成されることを確認
3. **コード直打ち中の未反映内容が課題切替・フリーモード復帰・答えを見る・
   全部消す・共有リンク復元で無警告に消える** →
   `src/app.js` に `confirmDiscardDirtyCode()` を追加し、該当5箇所すべてに適用。
   反映を試みて失敗する場合は確認ダイアログを出し、「戻る」を選べば処理を中止する。
   確認: キャンセル時は課題が切り替わらずコードも保持、続行時は正しく破棄されて
   ステータスバッジも消えることを実ブラウザで確認
4. **t01/t02/t06がブロック不使用の直接セル入力だけで誤クリアする** →
   `src/app.js` の `checkQuestClear()` に `view.steps.length > 0` のゲートを追加。
   確認: ブロック無しでA1に直接入力してもクリアバナーが出ないこと、
   実際にブロックを実行した場合は従来どおりクリアすることを確認
5. **CDN読み込み失敗時にエラー表示が無くフリーズしたように見える** →
   `index.html` の各CDN `<script>` に `onerror="cdnLoadFailed(...)"` を追加し、
   失敗時に再読み込み案内を全画面表示。確認: `cdnLoadFailed()` を直接呼び、
   案内メッセージが表示されることを確認
6. **複数タブ間でlocalStorageが後勝ちで上書きされる** →
   `src/app.js` に `storage` イベントリスナーを追加。`solved` は合算（減らさない）、
   `savedBlocks`/`savedInitial` は「今のタブで編集中でない課題」だけ取り込む。
   確認: 他タブでの `t03` クリアが `storage` イベント経由で取り込まれ、
   クエスト一覧に✓が付くことを確認
7. **テーマ切替でワークスペースのグリッド色が更新されない** →
   `src/app.js` に `updateWorkspaceGridColour()` を追加し `applyTheme()` から呼ぶ。
   Blockly 11.2.1 の `Grid` に色変更APIが無いため、内部の `line1`/`line2` SVG要素の
   `stroke` 属性を直接更新。確認: ダーク→ライト→ダークの往復で正しく変わることを確認
8. **InputBoxがループ内で1回しか聞かれず実Excelと挙動が乖離** →
   `src/excel-preview.js` の `Interpreter` に `inputCallCounts` を追加し、
   同じブロックでも反復ごとに別キャッシュキー（`block.id + "#" + 反復回数`）を使うよう修正。
   確認: 3回ループでprompt が3回呼ばれ、A1〜A3に別々の値が入ることを確認
9. **`navigator.clipboard` が使えない環境でコピー/共有が無言で失敗する** →
   `src/app.js` の copy-btn / share-btn ハンドラに存在チェックと `.catch()` を追加し、
   失敗時は `alert()`/`prompt()` で代替手段を提示。確認: clipboard未定義状態でも
   例外を投げず案内が出ることを確認
10. **PLAN.mdの決定事項「答えはコードのみ」が実装と食い違っていた** →
    `PLAN.md` の該当行を実装（ブロックも読み込む）に合わせて更新
